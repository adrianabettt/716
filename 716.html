O que significa decompor um problema na computação?

A
Criar um programa muito longo e complexo de uma só vez.
B
Dividir o problema em partes menores, mais fáceis de resolver.
C
Apagar o problema e começar outro diferente.
D
Usar um programa pronto da internet sem modificar nada.
2

O que é reúso no contexto da programação?

A
Escrever todo o código do zero sempre que precisar de uma solução.
B
Deletar partes antigas do programa para criar espaço.
C
Aproveitar funções ou soluções já criadas em outros contextos.
D
Copiar o trabalho de outro colega sem colaborar.

O que significa "automatizar" um algoritmo?

A
Fazer o algoritmo funcionar somente com a ajuda de um professor.

Qual conceito o código demonstra ao chamar calcular_area três vezes em vez de repetir a fórmula?

A
Decomposição, pois o problema foi dividido em triângulos menores.

D
Colaboração, pois vários programadores escreveram juntos.
